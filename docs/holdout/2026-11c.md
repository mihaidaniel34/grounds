## How the third set was chosen

Written before any finding was looked at.

The first two sets are spent: pull requests #70, #74, #76, #78, #80 and #84
fixed causes found on them. A third set of 20 projects measures current
master the same way. The rules for choosing it:

- **Fresh.** No project is in corpus/projects.tsv, corpus/smoke.tsv or either
  earlier set of corpus/holdout.tsv, and none is a fork (GitHub's `fork` flag
  was checked for every one) or a copy of one.
- **The same mix as before**: Maven and Gradle builds; from about 10,000 to
  several hundred thousand lines; Spring Boot applications and libraries,
  plain Spring, Micronaut, Quarkus, Jakarta EE/CDI, Guice and plain
  libraries; some heavy Lombok users.
- **Alive**: pushed to in 2026 where possible, pinned to the head of the
  default branch on 2026-11-11.
- Chosen from what the author knew of the Java ecosystem, before any of them
  was run. No project was dropped or added after a run.

Considered and rejected:

- **macrozheng/mall-swarm**: the microservice version of macrozheng/mall,
  which is in corpus/smoke.tsv, and shares much of its code; a copy.
- **yangzongzhuan/RuoYi-Vue**: YunaiV/ruoyi-vue-pro (smoke) grew out of it;
  too close to call fresh.
- **Netflix/conductor**: conductor-oss/conductor (set 2) is its continuation.
- **CodePhiliaX/Chat2DB**: wanted as a Lombok-heavy Spring Boot app, but the
  repository could not be reached; replaced by apache/streampark.
- **weld/core**: a CDI implementation rather than code using CDI, and the set
  already had three CDI/Quarkus projects; left out to keep 20.
- **apache/druid, apache/james-project, sonatype/nexus-public** (Guice): very
  large; graylog was taken as the one very large Guice project and eureka as
  a small one.
- **square/okhttp, square/moshi**: mostly Kotlin now.
- **eclipse/jnosql, real-logic/agrona**: the old names; taken under their
  current owners (eclipse-jnosql, aeron-io).
