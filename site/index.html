Static analysis for Java, fast enough to run after every edit.

grounds reports bugs, compile breaks and Spring or Micronaut wiring mistakes in the code you just changed, in 0.1–0.3 seconds. No Gradle, Maven or JVM: written in Rust, for coding agents and CI.
