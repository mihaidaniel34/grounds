Static analysis for Java, fast enough to run after every edit.

grounds reports bugs, compile breaks and Spring or Micronaut wiring mistakes in the code you just changed, in 0.1–0.3 seconds. It reads sources and jars directly: no Gradle, Maven or JVM. Written in Rust, for coding agents and CI.

v0.0.11 · experimental · Apache-2.0
